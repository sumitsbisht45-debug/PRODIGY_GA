# PRODIGY_GA_01 - Text Generation with GPT-2

## Internship Task 01

This project was completed as part of the Prodigy Infotech Generative AI Internship.

## Task Objective

The objective of this task is to train and fine-tune a GPT-2 transformer model on a custom dataset and generate coherent and contextually relevant text based on a given prompt.

## Technologies Used

- Python
- Google Colab
- PyTorch
- Hugging Face Transformers
- Hugging Face Datasets
- GPT-2
- Accelerate

## Project Workflow

1. Installed the required Python libraries.
2. Imported PyTorch, Transformers, and Datasets libraries.
3. Checked the available hardware and GPU.
4. Created and loaded a custom text dataset.
5. Prepared the dataset for training.
6. Loaded the pre-trained GPT-2 model.
7. Loaded the GPT-2 tokenizer.
8. Tokenized the training examples.
9. Configured the training parameters.
10. Fine-tuned the GPT-2 model using the training dataset.
11. Generated text using a custom prompt.
12. Evaluated the generated output.

## Dataset

A small custom dataset containing 20 training examples was used for this task.

The dataset was prepared as text examples related to artificial intelligence, technology, machine learning, and related topics.

## Model

The project uses the pre-trained **GPT-2** language model.

GPT-2 is a transformer-based language model developed by OpenAI that can generate human-like text based on a given prompt.

## Training

The GPT-2 model was fine-tuned using the custom dataset.

The training process used:

- PyTorch
- Hugging Face Transformers
- Trainer API
- Data Collator for Language Modeling
- GPU acceleration through Google Colab

## Text Generation

After training, the model was given a prompt:

`Artificial intelligence is`

The fine-tuned model generated contextually relevant text based on the learned training data.

## Sample Output

The model generated text related to artificial intelligence, technology, machine learning, and research.

Example generated text included sentences discussing artificial intelligence, companies, researchers, and technological development.

## Result

The task successfully demonstrated the complete workflow of fine-tuning GPT-2 on a custom dataset and generating text from a user-provided prompt.

The model was successfully loaded, trained, and used for text generation.

## Conclusion

This project provided practical experience with transformer-based language models, dataset preparation, tokenization, model fine-tuning, and text generation.

It also demonstrated how a pre-trained GPT-2 model can be adapted to generate text that follows the style and topics of a custom training dataset.
