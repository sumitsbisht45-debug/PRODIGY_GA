# PRODIGY_GA_03 - Text Generation with Markov Chains

## Generative AI Internship - Prodigy Infotech

This project was completed as part of my Generative AI Internship at Prodigy Infotech.

## About the Task

The objective of this task was to implement a text generation model using a Markov Chain.

A Markov Chain is a statistical model that predicts the next word based on the current word and the transition patterns learned from the training text.

For this task, I created a custom text dataset related to artificial intelligence, machine learning, technology, programming, and learning. The dataset was then processed and used to build a word-level Markov Chain model.

## Objective

The main objectives of this task were:

- To understand how Markov Chains work for text generation.
- To prepare and preprocess a text dataset.
- To build a word-level Markov Chain model.
- To learn word-to-word transition patterns from the text.
- To generate new text based on a starting word.
- To test the model using different starting words.
- To save the generated text for further reference.
